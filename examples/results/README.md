# Published benchmark examples

| Experiment | Hardware | Models | Evidence |
| --- | --- | --- | --- |
| [November 9, 2026](apple-m2-pro-16gb/README.md) | Apple M2 Pro, 16 GB unified memory | LFM3 1.7B, Qwen3.5 4B, Spark X2.6 4B; additional Qwen MLX check | Reports, CSV/JSON, methodology, transcripts and logs |

These are measured local observations, not simulated/demo timings. The first experiment used the earlier Mac-specific harness; its JSON schema differs from the portable CLI. Each example documents its settings and limitations. New private runs belong in the repository-root `results/` directory, which remains ignored by Git.
